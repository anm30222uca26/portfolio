# Portfolio

A clean, responsive portfolio template with dark mode, projects grid, and contact form.

## Getting started

- Open `index.html` in your browser (double-click it). No build step needed.
- Edit your name in `index.html` (`[Your Name]`), update bio, and links.
- Replace images in `assets/images/` or adjust paths in `assets/js/main.js`.

## Customize

- Colors and theme variables are in `assets/css/styles.css` under `:root`.
- Skills and projects are defined in `assets/js/main.js` (`skills` and `projects`).
- Favicon: place `favicon.ico` in `assets/images/` and adjust `<link rel="icon">` if needed.

## Features

- Dark/light theme with localStorage preference
- Mobile-friendly nav and responsive grid
- Accessible landmarks and focusable elements

## Deploy

- You can host this on GitHub Pages, Netlify, or Vercel by deploying the folder as a static site.
